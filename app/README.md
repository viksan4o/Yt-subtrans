# BG Subs – приложение (Flutter, Windows)

Поставяш линк към YouTube видео, натискаш **Преведи** и виждаш напредъка, а после списъка с преведените реплики.
(Плейърът с надписи върху видеото е следващата стъпка.)

## Пускане

```powershell
cd "C:\Users\thoma\Desktop\Bg translater\app"
flutter run -d windows
```

## Настройки (иконата с зъбно колело)

- **Доставчик:** Gemini (безплатен ключ от aistudio.google.com), Ollama (локално, без ключ) или Claude (платен).
- **API ключ:** пази се само на този компютър, в `%APPDATA%\BG Subs\settings.json`. Никога не влиза в git.
  Ако полето е празно, двигателят ползва ключа от `engine\.env`.
- **Модел и лимити:** празно = стойностите по подразбиране на двигателя. Бутоните „Качество“ и „Голям обем“ ги попълват.
- **Двигател:** празно = вграденият. Приложението търси `engine\subtrans.exe` до себе си (за готовата версия),
  а иначе папката `engine` в това хранилище и Python от `.venv`.

## Тестове

```powershell
flutter test
```

Един от тестовете пуска истинския двигател с фалшив преводач (сваля субтитрите на кратко видео от YouTube).
